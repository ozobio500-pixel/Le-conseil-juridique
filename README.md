# Le Conseil Juridique

Plateforme web responsive de gestion de l'assistance juridique du Centre
l'Espoir, ONG basée à Grand-Bassam, en Côte d'Ivoire.

## Contenu disponible

- `01-cadrages/cahier-des-charges.docx` : cahier des charges structuré à partir
  des informations fournies.
- `01-cadrages/presentation-entreprise.docx` : présentation du Centre l'Espoir.
- `01-cadrages/presentation-projet.pptx` : présentation du projet en 13 diapositives.
- `02-modelisation/drawio/` : diagrammes de cas d'utilisation, de classes et
  d'activité au format draw.io.
- `02-modelisation/plantuml/` : huit diagrammes de séquence.

## Éléments à compléter

- `01-cadrages/pieces-jointes/` : entretiens ONG et documents annexes.
- `02-modelisation/exports/` : exports PNG, à générer après finalisation des
  diagrammes.
- `03-documentation/` : guide technique et manuel utilisateur, prévus pour les
  phases de développement et de déploiement.
- Dépôt Git : à initialiser et publier.

Les informations à confirmer (notamment budget, dates, technologies et droits
d'accès) sont signalées dans le cahier des charges. La procédure d'export et la
checklist figurent dans [`03-documentation/README.md`](03-documentation/README.md).
